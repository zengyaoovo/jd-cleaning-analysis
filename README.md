\# 京东电商评论数据清洗与多维分析实战



基于 Python 的电商用户评论数据全链路实战项目：从原始脏数据清洗，到特征工程、探索性数据分析（EDA），再到 NLP 文本挖掘与多维可视化，完整跑通了一套标准化、可复用的数据分析工作流。



\## 项目背景



电商平台的用户评论是非结构化文本，里面既包含了用户对产品的真实反馈，也隐含着用户画像、消费习惯、购买时段等有价值的商业信息。本项目以京东手机评论为样本，尝试从这些杂乱的数据中提炼出可支撑业务决策的洞察。



\## 技术栈



\- \*\*语言与工具\*\*：Python、Jupyter Notebook

\- \*\*数据处理\*\*：Pandas、NumPy、Regex、JSON

\- \*\*机器学习/NLP\*\*：Scikit-learn（LabelEncoder）、Jieba 分词

\- \*\*数据可视化\*\*：Pyecharts（Bar / Line / Pie / Timeline）、WordCloud、Matplotlib



\## 核心工作流



\### 1. 数据清洗（Data Cleaning）

\- 缺失值填充与数据类型转换

\- 正则匹配过滤无效评论（未填写评价内容、默认好评等）

\- 基于多字段的业务逻辑去重

\- Unix 时间戳转换与时区处理



\### 2. 特征工程（Feature Engineering）

\- 分类变量编码：会员等级、商品 SKU、商品 ID

\- 时间维度拆解：年、月、小时



\### 3. 探索性数据分析（EDA）

\- \*\*用户画像\*\*：各会员等级评价占比及每月趋势（折线图）

\- \*\*行为洞察\*\*：一天 24 小时评价时段分布（柱状图）

\- \*\*口碑分析\*\*：评分分布饼图与高频评价标签 Top20

\- \*\*文本挖掘\*\*：基于 Jieba 分词与停用词过滤的词云图

\- \*\*商品维度\*\*：历年商品评论量 Top10 动态时间轴图
